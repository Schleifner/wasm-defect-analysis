# Knowledge Base

This directory contains reusable, source-grounded lessons learned after human review. It must not become a list of speculative bug patterns.

- `verdict-policy.md` defines stable triage rules.
- `templates/finding.md` is the human-readable dossier format for a promoted finding.

Add a lesson only after evidence changes a decision or exposes a recurring search failure. Link the originating run and target commit. Validation and holdout labels must stay out of agent-visible lessons until their evaluation cycle is complete.
